# SigmaGPT — Frontend

Developed and maintained by **Harshvardhan Singh**  
GitHub: [https://github.com/harshvardhansinghbhanawat-glitch](https://github.com/harshvardhansinghbhanawat-glitch)

This is the React + Vite frontend for SigmaGPT, providing a ChatGPT-inspired AI chat experience with authentication, thread history management, and multi-tier plan selections.

## Development

```powershell
npm install
npm run dev
```

## Production Build

```powershell
npm run build
```

## Environment Variables

| Variable | Description |
|---|---|
| `VITE_API_URL` | Base URL for SigmaGPT backend API (e.g. `https://sigmagpt-api.onrender.com/api` or `/api` locally) |
